Recycling Rules Helper

A grounded campus recycling assistant that answers HKU recycling questions only from official waste-reduction sources, refuses unsafe or misleading instructions, and asks for clarification when a question is too vague — never inventing facts.

Rule-based classifier LLM polish (Alibaba Cloud Qwen) 15/15 evaluation pass Domain customised to HKU waste policy
A1 · Sections 1–2

Who it is for & the problem

Campus members (students, staff, visitors) often do not know whether a specific item is recyclable at HKU, or must be cleaned first. Generic chatbots confidently guess and invent rules, which spreads mis-sorting. Our tool answers strictly from the four official HKU Waste Reduction sources.

4

Official sources

Recycling 101, Photo Guide, re Facilities, Ditch Disposables — the only evidence the model may cite.

5

Response buckets

Supported · Needs-clarification · Unsupported · Refusal · each routed deterministically.

15

Evaluation cases

Normal, boundary (vague "a cup"), unsupported (laptop/e-waste) and refusal cases.

A1 · Pipeline

How it works: input → processing → output

A deterministic rule layer decides what is true and which sources apply; the LLM is used only to polish wording within those sources, and silently falls back to the local official draft on any failure.

A1 · Domain customisation

Genuine domain customisation

This is not a generic LLM wrapper. The behaviour is specialised to HKU's recycling domain and is supported by implementation and results:

  • Grounded to official policy: the model may only use the four HKU Waste Reduction sources; if a question falls outside them it answers "insufficient information" instead of guessing.
  • Boundary handling: vague items ("a cup") trigger a clarification request rather than a confident wrong answer (T12).
  • Refusal of misleading premises: "Are all batteries general waste?" is refused and corrected using S1/S3 — rechargeable batteries must go to designated stations (T15).
  • Out-of-scope guard: e-waste / laptop disposal is flagged unsupported and redirected to official channels (T14).
  • A design choice validated by results: deterministic rules fix the facts and citations so that evaluation is stable 15/15 regardless of LLM variability — the LLM never changes correctness, only phrasing.

Set up and run

The full source is in the team's staff-accessible GitHub repository (link below). No secrets are committed — the key is read from a local .env.

git clone # see repository link below
cd Ailt-9019-Group47

A2 · Evaluation, failure case & limitations

Results, failure / boundary case & limitations

Evidence: python app.py --eval passes 15/15 cases. With --llm the wording is polished by Qwen but the cited sources and facts stay identical; any LLM error falls back silently to the local official draft, so correctness is preserved.
CaseTypeQuestionSystem behaviour
T04SupportedWhat can I recycle at HKU?Lists clean paper/cardboard/glass/plastic/metal; rechargeable batteries → designated stations (S1).
T12ClarifyCan I recycle a cup?Boundary: too vague — asks for material & cleaning status instead of guessing.
T14UnsupportedHow do I recycle my old laptop?Out of scope — states insufficient info and points to official e-waste channels.
T15RefusalAre all batteries general waste?Failure/misleading case: refuses the false premise, corrects with S1/S3.

Limitations & evidence-based improvements

  • Retrieval is keyword-based, not semantic. Unusual phrasing can fall to the default bucket. Improvement: add embedding-based retrieval over the sources.
  • Source freshness. Rules mirror sources captured on 2026-11-19; policy changes need re-ingest. Improvement: scheduled re-scrape with change detection.
  • Single-turn. Clarification requires the user to re-ask. Improvement: session context to continue after a needs-clarification turn.

Ethics & privacy

All answers are derived from public HKU Waste Reduction pages. No personal data is collected or processed. The team API key lives only in a local .env, never in code or in this public page; the API is used for course work only, without excessive concurrency.

AI-use disclosure

An LLM (Alibaba Cloud Qwen qwen3.8-flash, via the Bailian Token Plan) polishes wording only, strictly within the selected official sources. All factual claims and citations are human-verified against the source pages; the deterministic rule layer guarantees grounded behaviour.
